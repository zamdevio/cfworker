# 2.0.0

Implemented the refactor phases on branch `refactor/cli-ts`. Not published.

## What landed

- Audit numbers are in `maintainer/notes/audit-baseline.md`.
- TypeScript source under `src/`, strict `tsc`, tsup with `bundle: false`, tsx for dev and tests.
- Auth scans Wrangler v4, Wrangler v3, and `~/.config/cfworker`. `login` validates the token. `profiles` shows the source.
- Commands load on use. Help does not import auth or the API client.
- Human output uses tables, a stderr spinner, and color that honors `NO_COLOR`.
- Download asks for a destination on a TTY, expands `~` and relative paths, stages in temp, and compares sha256 before writing.
- Multipart detection requires a boundary and `Content-Disposition`. Split rejects paths that escape the output directory and does not follow symlinks outward.
- Tests, Biome, knip, madge, and `.github/workflows/ci.yml`. `pnpm pack` includes `bin/` and `dist/`.

## Decisions

- ESM only.
- tsup, not a bundled single file, so dynamic command imports stay lazy.
- In-house prompts. No prompt dependency.
- No state directory. Dedup hashes the destination.
- Non-interactive default remains `./recovered/<worker>`, from the current directory rather than the package root.
